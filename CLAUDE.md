# КонтентЗавод

Контент-завод с нулевым бюджетом: генерация и публикация контента (посты + вертикальные видео) для нескольких проектов в Telegram, VK, YouTube Shorts, Instagram, Яндекс.Дзен. Полуавтомат: генерация → ревью в дашборде → публикация по календарю → аналитика → самообучение (learnings).

Связанный проект: **LLM-Router** (`A:\DevAI\Projects\LLMRouter`) — отдельный self-hosted LLM-шлюз (пул ключей, приоритет бесплатных, один универсальный ключ). Его план и состояние тоже трекаются ЗДЕСЬ (PLAN.md / STATE.md).

## Протокол сессии (ОБЯЗАТЕЛЬНО)

1. **Старт:** прочитай `STATE.md`, затем нужный раздел `PLAN.md`. НЕ сканируй проект целиком — вся точка входа в этих двух файлах. Если пользователь сказал «продолжай» — продолжай с «Следующего шага» из STATE.md.
2. **Схема работы — оркестратор + сабагенты.** Главная сессия (любая модель) — ОРКЕСТРАТОР: читает состояние, принимает решения, ставит задачи, проверяет результат, обновляет STATE/PLAN. Сам код руками почти не пишет — РАБОТУ ДЕЛАЮТ САБАГЕНТЫ с моделью по сложности:
   - `coder-simple` (haiku) — boilerplate, CRUD, шаблоны/HTML, конфиги, мелкие правки;
   - `coder` (sonnet) — основная логика, интеграции, тесты;
   - `architect` (opus) — архитектура, сложный дебаг, ffmpeg filter graph, логика роутинга/анализа.
   Если кастомные агенты не подхватились — используй обычный сабагент с параметром model (haiku/sonnet/opus). Не используй opus там, где справится haiku. В промпт сабагенту давай полное ТЗ: файлы, интерфейсы, ограничения — он стартует с нуля.
3. **После КАЖДОГО цикла работы** (завершил блок/задачу — не только в конце сессии!): отметь чекбоксы в `PLAN.md`; обнови в `STATE.md` текущую точку и следующий шаг. Узнал неочевидное (грабли, лимит API, особенность платформы) — сразу допиши в `STATE.md → Нюансы`. Правило: после любого изменения кода STATE.md не должен отставать — ничего не теряем.
4. **Финиш сессии:** финально обнови `STATE.md`: что сделано и с каким результатом (честно: «тесты прошли» / «застрял на X»), следующий шаг. Важные решения — в `PLAN.md → Журнал решений`. Stop-хук (`.claude/hooks/check-state.ps1`) не даст завершить ответ, если STATE.md отстал от изменений файлов.

## Ограничения (не нарушать)

- Сервер: 4GB RAM / 2 vCPU / 30GB SSD. Стек: Python, FastAPI, SQLite, APScheduler, Jinja2+HTMX, чистый ffmpeg. Никаких Postgres/Redis/Celery/n8n/moviepy/docker-компостов.
- Деньги: только DeepSeek API. Всё остальное — бесплатное (free-тиры, edge-tts, Pexels/Pixabay, Pollinations).
- LLM-вызовы из завода — ТОЛЬКО через LLM-Router (openai SDK, base_url роутера), не напрямую к провайдерам.
- Секреты — в `.env` (DeepSeek-ключ уже лежит в `A:\DevAI\Projects\KontentZavod\.env`), в git не коммитить. Ключи аккаунтов в роутере — шифровать (Fernet).
- Промпты генерации — отдельными файлами в `app/prompts/`, не в коде.

## Команды

- Завод: `uvicorn app.main:app --reload` (когда появится)
- Роутер: `uvicorn app.main:app --reload --port 8100` (в LLMRouter, когда появится)
