## ЗАДАЧА

Напиши тексты поста для всех указанных площадок. Для каждой площадки:
1. **Хук в первой строке** — зацепи читателя немедленно. Типы хуков: вопрос, шокирующий факт, провокация, история «я», обещание результата.
2. **Тело** — раскрой идею по существу, конкретно и с пользой для ЦА.
3. **CTA в конце** — призыв к действию из профиля проекта, органично вписанный в текст.

Адаптируй тон, длину и форматирование под специфику каждой площадки (требования указаны выше).

## ФОРМАТ ОТВЕТА

Ответь СТРОГО валидным JSON без каких-либо пояснений — только JSON-объект:

```json
{
  "title": "Краткий заголовок поста (до 80 символов)",
  "telegram": {
    "text": "Полный текст для Telegram",
    "hashtags": ["#тег1", "#тег2", "#тег3"]
  },
  "vk": {
    "text": "Полный текст для VK",
    "hashtags": ["#тег1", "#тег2"]
  },
  "youtube": {
    "title": "Название видео для YouTube Shorts (до 100 символов)",
    "description": "Описание для YouTube",
    "hashtags": ["#shorts", "#тег1"]
  },
  "instagram": {
    "caption": "Подпись для Instagram (первые 125 символов решают — хук сюда!)",
    "hashtags": ["#тег1", "#тег2", "#тег3"]
  },
  "dzen": {
    "title": "Заголовок статьи для Яндекс.Дзен",
    "text": "Полный текст статьи (Markdown)"
  },
  "features": {
    "hook_type": "вопрос",
    "topic": "основная тема поста",
    "length": "medium",
    "format": "text",
    "ab_variant": "null"
  }
}
```

**Важно:** включай в JSON ТОЛЬКО те площадки, которые перечислены в разделе «Активные площадки». Ключи `title` и `features` — обязательны всегда.

**Значения для features:**
- `hook_type`: одно из — `вопрос`, `факт`, `история`, `провокация`
- `length`: `short` (до 500 символов), `medium` (500–1500), `long` (1500+)
- `format`: `text`, `carousel`, `reel`
- `ab_variant`: `A`, `B` или `null`
