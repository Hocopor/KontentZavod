## Требования к стратегии
- Для каждой подключённой площадки задай: цели (goals), 3–5 рубрик с КОНКРЕТНЫМ описанием
  (что это и зачем), контент-микс (сколько штук КАЖДОГО включённого типа в НЕДЕЛЮ — реалистично
  для небольшой команды, без перегруза), 2–3 лучших времени публикации (с учётом специфики
  платформы и аудитории), измеримый KPI.
- content_mix содержит ТОЛЬКО включённые для этой площадки типы (ключи — точные коды типов).
- Рубрики — это повторяющиеся форматы, по которым пойдёт контент-план. Описывай их так, чтобы
  по ним можно было ставить задачи.
- summary — краткое резюме стратегии (2–4 предложения). positioning — позиционирование бренда.

## Формат ответа
Верни ТОЛЬКО валидный JSON, без пояснений и без markdown-фенсов. Структура:

{
  "summary": "Краткое резюме стратегии",
  "positioning": "Позиционирование бренда одной-двумя фразами",
  "platforms": {
    "telegram": {
      "goals": "Цели по этой площадке",
      "rubrics": ["Рубрика 1 — описание", "Рубрика 2 — описание"],
      "content_mix": {"post": 4, "video": 2},
      "best_times": ["09:00", "18:00"],
      "kpi": "Измеримый показатель успеха"
    }
  }
}

Включи в platforms ТОЛЬКО площадки из списка выше. Никакого текста вне JSON.
