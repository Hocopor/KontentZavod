## ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ ВИДЕО

- Формат: вертикальный ролик 9:16 (1080×1920)
- Длительность: не более 60 секунд
- Суммарный объём озвучки: 130–150 слов (соблюдать строго!)
- Сцен: 4–8 (каждая сцена — один кадр с подложкой)
- Голос озвучки: dmitry (мужской) или svetlana (женский) — выбери подходящий для тона
- Настроение фона: energetic | calm | inspiring | neutral
- Первая сцена — обязательный ХУК (зацепи зрителя в первые 3 секунды)
- Последняя сцена — CTA (призыв к действию из профиля проекта)

## ЗАДАЧА

1. Напиши сценарий вертикального ролика ≤60 секунд (130–150 слов озвучки суммарно).
2. Раздели на 4–8 сцен. Каждая сцена: 1–2 предложения озвучки + английские ключевые слова для поиска видеофутажа/картинки.
3. Keywords для сцен — ТОЛЬКО английские слова (используются для поиска на Pexels/Pixabay/Openverse/Wikimedia). Примеры: ["coffee shop", "barista", "espresso"] — НЕ по-русски.
4. Напиши посты-обвязки для включённых площадок (требования указаны выше). Посты должны дополнять видео, а не копировать его текст дословно.

## ФОРМАТ ОТВЕТА

Ответь СТРОГО валидным JSON без каких-либо пояснений — только JSON-объект:

```json
{
  "title": "Краткий заголовок видео (до 80 символов)",
  "video": {
    "voice": "dmitry",
    "mood": "energetic",
    "scenes": [
      {
        "text": "Фраза озвучки первой сцены — ХУК. 1-2 предложения.",
        "keywords": ["english", "search", "keywords"]
      },
      {
        "text": "Фраза озвучки второй сцены. 1-2 предложения.",
        "keywords": ["more", "english", "keywords"]
      }
    ]
  },
  "telegram": {
    "text": "Текст поста для Telegram",
    "hashtags": ["#тег1", "#тег2"]
  },
  "vk": {
    "text": "Текст поста для VK",
    "hashtags": ["#тег1", "#тег2"]
  },
  "youtube": {
    "title": "Название видео для YouTube Shorts (до 100 символов)",
    "description": "Описание для YouTube",
    "hashtags": ["#shorts", "#тег1"]
  },
  "instagram": {
    "caption": "Подпись для Instagram (первые 125 символов — хук!)",
    "hashtags": ["#тег1", "#тег2"]
  },
  "features": {
    "hook_type": "вопрос",
    "topic": "основная тема видео",
    "length": "short",
    "format": "reel",
    "ab_variant": "null"
  }
}
```

**Важно:**
- `video` — обязателен всегда. Суммарно по всем сценам: 130–150 слов.
- `title` — обязателен всегда.
- `features` — обязателен всегда. `format` должен быть `"reel"`.
- Блоки площадок (telegram, vk, youtube, instagram) — только для тех, что перечислены в разделе «Активные площадки». Dzen для видео не нужен — никогда не включай.
- `keywords` в каждой сцене — ТОЛЬКО английские слова, массив строк, минимум 2 слова.
- `voice`: `"dmitry"` (мужской) или `"svetlana"` (женский).
- `mood`: одно из — `"energetic"`, `"calm"`, `"inspiring"`, `"neutral"`.

**Значения для features:**
- `hook_type`: одно из — `вопрос`, `факт`, `история`, `провокация`
- `length`: `"short"` (видео до 30с), `"medium"` (30–60с)
- `format`: всегда `"reel"`
- `ab_variant`: `"A"`, `"B"` или `"null"`
