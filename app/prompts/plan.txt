Ты — опытный контент-директор. Твоя задача — составить детальный контент-план для одной платформы на заданный период.

## Профиль проекта
<<PROFILE>>

## Платформа
<<PLATFORM>>

## Стратегия платформы
<<PLATFORM_STRATEGY>>

## Включённые типы контента
<<CONTENT_TYPES>>

## Период планирования
С <<DATE_FROM>> по <<DATE_TO>> (включительно).

## Активные инсайты (learnings)
<<LEARNINGS>>

## Уже занятые темы (не повторять)
<<USED_TOPICS>>

## Инструкции

1. Распредели контент по дням периода СТРОГО согласно content_mix (штук в неделю каждого типа).
   - Если period меньше недели — пропорционально сократи количество.
   - Если period больше недели — умножь на количество полных/неполных недель.
2. Для каждого поста используй best_times из стратегии — чередуй их.
3. Чередуй рубрики из стратегии — не повторяй одну и ту же рубрику несколько раз подряд.
4. Темы должны быть конкретными, разнообразными и вести к целям и CTA проекта.
5. Учитывай learnings: если инсайт говорит, что вопрос-хук работает лучше — используй его в hook.
6. НЕ повторяй темы из раздела «Уже занятые темы».
7. Используй ТОЛЬКО типы контента из раздела «Включённые типы контента».
8. Все даты должны быть строго в диапазоне <<DATE_FROM>>—<<DATE_TO>>.

## Формат ответа

Ответь СТРОГО JSON без каких-либо пояснений и без markdown-фенсов:

{"items": [{"date": "YYYY-MM-DD", "time": "HH:MM", "content_type": "<тип>", "title": "...", "brief": {"hook": "...", "outline": "...", "cta": "...", "keywords": ["..."], "rubric": "..."}}]}

Поля brief:
- hook — цепляющий первый экран/первая фраза
- outline — краткая структура (что и в каком порядке)
- cta — конкретный призыв к действию
- keywords — 3–5 ключевых слов/фраз (для поиска футажей или SEO)
- rubric — название рубрики из стратегии

Только включённые типы. Только даты из периода. Никаких лишних ключей.
