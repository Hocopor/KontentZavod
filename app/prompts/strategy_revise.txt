## Требования
- Сохрани структуру стратегии. Для каждой подключённой площадки: goals, 3–5 рубрик с описанием,
  content_mix (только включённые типы, реалистично для небольшой команды, штук/неделю),
  2–3 best_times, измеримый kpi.
- Учти комментарий пользователя как приоритет, опирайся на метрики.
- Добавь поле changes_summary — что именно изменилось относительно прошлой версии и почему.

## Формат ответа
Верни ТОЛЬКО валидный JSON, без пояснений и без markdown-фенсов:

{
  "summary": "Обновлённое резюме",
  "positioning": "Позиционирование",
  "platforms": {
    "telegram": {
      "goals": "...",
      "rubrics": ["Рубрика — описание"],
      "content_mix": {"post": 3, "video": 3},
      "best_times": ["09:00", "19:00"],
      "kpi": "..."
    }
  },
  "changes_summary": "Что изменилось и почему"
}

Включи в platforms ТОЛЬКО площадки из списка. Никакого текста вне JSON.
