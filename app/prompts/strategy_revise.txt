## Требования
- Сохрани структуру по ФАЗАМ (2–4 фазы, у каждой weeks 1–4, name, objective, goal_share с суммой 100,
  mix — штук каждого включённого типа в неделю per площадка, notes). Доля sell растёт постепенно.
- Кампания ПРОДОЛЖАЕТСЯ, а не начинается заново: НЕ переписывай задним числом якорь activated_on
  и уже пройденные фазы. Меняй текущую и БУДУЩИЕ фазы — добавляй/корректируй их.
- rubrics — массив объектов {name, goal, description}, goal из {attract, retain, sell, brand}.
- Если директива задаёт количество — mix обязан ему соответствовать ТОЧНО.
- НЕ задавай content_mix в platforms — количество диктуют фазы.
- Учти комментарий пользователя как приоритет, опирайся на метрики.
- Добавь поле changes_summary — что именно изменилось относительно прошлой версии и почему.

## Формат ответа
Верни ТОЛЬКО валидный JSON, без пояснений и без markdown-фенсов:

{
  "summary": "Обновлённое резюме",
  "positioning": "Позиционирование",
  "phases": [
    {
      "n": 1, "weeks": 2, "name": "Прогрев",
      "objective": "удерживать интерес",
      "goal_share": {"attract": 40, "retain": 45, "sell": 15},
      "mix": {"telegram": {"post": 5, "video": 3}},
      "notes": "акцент на видео"
    }
  ],
  "platforms": {
    "telegram": {
      "goals": "...",
      "rubrics": [
        {"name": "Видео-совет", "goal": "attract", "description": "короткий полезный ролик"}
      ],
      "best_times": ["09:00", "19:00"],
      "kpi": "..."
    }
  },
  "changes_summary": "Что изменилось и почему"
}

Включи в platforms и в mix фаз ТОЛЬКО площадки и типы из списка. Никакого текста вне JSON.
